# BL4 LAN · by skykindness

**0.2.13** · [Русский](README-RU.md) · [English](README-EN.md)

《无主之地 4》局域网 / VPN 联机模组。启动器支持创建主机、按 IP 加入好友和修改昵称。0.2.13 修复了创建主机后首次发现避难所时任务和数据板缺失的问题。[前往 Releases 下载](https://github.com/Skykindness/BL4-LAN/releases) · [查看问题排查和修复过程](https://github.com/Skykindness/BL4-LAN/blob/main/docs/SAFEHOUSE-FIX-ZH-CN.md)

## 如何联机

1. 双方先关闭游戏，完整解压 `BL4-LAN-v0.2.13.zip`。运行 `BL4-LAN.exe`，选择包含 `OakGame` 的游戏根目录，再点击 **“安装 / 更新”**。首次使用或更新时安装一次即可。
2. 双方使用相同的游戏版本和模组版本，并加入同一局域网或同一个 Radmin VPN 网络。使用 VPN 时，请填写主机在该网络中的 IP 地址。
3. 双方在游戏中点击 **“继续”**，先将各自的角色加载到游戏世界。主机点击 **“创建主机”** 并等待区域重新加载。好友点击 **“连接”**，输入主机地址，例如 `26.1.2.3:7777`。保持启动器运行。

启动器语言可选 **RU / EN / 简体中文**。在启动器设置中修改昵称，重启游戏后生效。

## 快捷键和命令

**F6** 创建主机，**F7** 按保存的地址加入，**F8** 查看状态。如果控制台显示文字版 `mods` 菜单，先按 **Q → Enter** 退出。

| 命令 | 用途 |
| --- | --- |
| `bl4lan host` | 加载角色后创建主机 |
| `bl4lan join IP:7777` | 通过主机地址加入 |
| `bl4lan status` | 查看会话状态 |

## 兼容性和故障排查

- 避难所修复仅在已验证的 `Oak2-Win64-4906557` 游戏版本上启用。
- 个人难度可在 **Esc → 会话设置 → 难度 → 应用** 中选择。好友加入时会保留所选难度。稀有战利品加成和 3–4 人难度缩放尚未验证。
- 右上角队伍头像与人数、游戏原有的“+”按钮、隔墙昵称以及部分 HUD 状态仍有限制。全流程和 3–4 人会话仍需单独验证。
- 遇到问题时，请收集双方游戏目录 `BL4-LAN-Data/Reports` 中的 ZIP 报告。报告不会自动上传，也不包含存档。

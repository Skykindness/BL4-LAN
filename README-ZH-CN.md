# BL4 LAN 0.2.12 · by skykindness

[Русский](README-RU.md) · [English](README-EN.md)

《无主之地4》局域网 / VPN 联机模组。本版修复了已复现的跨区域传送卡死，并为启动器加入简体中文。

1. 双方先关闭游戏，解压**完整压缩包**。运行 BL4-LAN.exe，选择包含 OakGame 的游戏根目录，点击“安装 / 更新”。首次使用或更新时安装一次即可。
2. 双方使用相同的游戏和模组版本，并加入同一局域网或同一个 Radmin VPN 网络。使用 VPN 时，请填写主机的 VPN 地址。
3. 双方在游戏中选择“继续”，先将各自的角色加载到自己的游戏世界。
4. 主机点击“创建主机”，等待区域重新加载。好友点击“连接”，输入主机 IP，例如 `26.1.2.3:7777`。
5. 保持启动器运行。语言下拉框可选择 RU / EN / 简体中文，所选语言会保存。昵称可在设置中修改，重启游戏后生效。

备用控制台命令：`bl4lan host` 创建主机，`bl4lan join IP:7777` 加入，`bl4lan status` 查看状态。F6 创建主机，F7 按已保存地址加入，F8 查看状态。若进入了文字版 mods 菜单，请先按 Q → Enter 退出。

个人难度：Esc → 会话设置 → 难度 → 应用。加入时保留好友选择的难度；稀有战利品加成及3–4人难度缩放尚未确认。

**已知限制：**在联机中首次发现新避难所时，可能不会触发任务或生成数据板，此问题尚未修复。右上角队伍头像/人数、原生“+”加入功能、隔墙昵称和部分 HUD 状态仍不完善。尚未完整验证全流程及3–4人联机。发行包不含 safehouse/pyexec 实验命令。

出现问题时，请提供双方游戏目录下 BL4-LAN-Data → Reports 中的 ZIP 报告。报告不会自动上传，也不包含存档。简体中文用于启动器，不会更改游戏本身的语言。

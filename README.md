# BL4 LAN · by skykindness

Играйте в Borderlands 4 с другом на двух компьютерах через локальную сеть или общую VPN. Лаунчер помогает установить мод, создать хост и подключиться по адресу.

**[Скачать готовую программу — Releases](https://github.com/Skykindness/BL4-LAN/releases)**

Для игры нужен архив **BL4-LAN-v0.2.1.zip**. Архив **BL4-LAN-Source-v0.2.1.zip** содержит исходники для разработчиков.

## Что понадобится обоим игрокам

- Borderlands 4 одинаковой сборки. Одного совпадения языка игры недостаточно.
- Одинаковый пакет BL4 LAN на обоих компьютерах.
- Общая домашняя сеть или одна виртуальная сеть.
- Каждый запускает свою копию игры и лаунчера.

**Хост** — человек, к которому подключается друг. Договоритесь заранее, кто будет хостом.

## Какую программу выбрать для сети

Для первого запуска рекомендуем **[Radmin VPN](https://www.radmin-vpn.com/ru/)**: это бесплатная программа для виртуальной локальной сети. Есть пользовательское сообщение об успешном подключении этого мода через Radmin.

Альтернативы: **[ZeroTier](https://www.zerotier.com/download/)**, **[Tailscale](https://tailscale.com/download)** и **[Hamachi](https://vpn.net/)**. С этим модом они отдельно не проверялись. Если выбрали альтернативу, настройте связь между компьютерами и используйте IPv4 хоста, выданный этой программой.

Если оба компьютера уже в одной домашней сети, VPN обычно не нужен: выбирайте адрес домашнего сетевого адаптера.

Обычный VPN для смены страны сам по себе не объединяет вас с другом в одну сеть.

## Шаг 1. Объедините компьютеры через Radmin VPN

Оба игрока устанавливают и открывают Radmin VPN с официального сайта.

**Что делает хост:**

1. Нажимает **«Создать сеть»**.
2. Придумывает название сети и пароль.
3. Создаёт сеть и передаёт название и пароль другу.

**Что делает друг:**

1. Нажимает **«Присоединиться к сети»**.
2. Указывает название и пароль, полученные от хоста.
3. Подключается. Оба должны видеть друг друга среди участников этой сети.

Название сети используется только для входа в Radmin. В BL4 LAN понадобится **IP-адрес компьютера хоста**.

При проблемах с самой сетью откройте [официальную справку Radmin VPN](https://www.radmin-vpn.com/ru/help/). В ней также описана проверка связи через контекстное меню участника.

## Шаг 2. Подготовьте мод — один раз на каждом компьютере

1. Скачайте **BL4-LAN-v0.2.1.zip** из раздела Releases.
2. Нажмите на архив правой кнопкой мыши и выберите **«Извлечь всё»**.
3. Откройте распакованную папку и запустите **BL4-LAN.exe**. Оставьте рядом с ним остальные файлы из архива.
4. В программе откройте **«Настройки»**.
5. Выберите папку установленной Borderlands 4 — внутри неё должна быть папка **OakGame**.
6. Вернитесь в раздел **«Играть»**.
7. Если появилась кнопка **«Установить мод»**, закройте игру и нажмите эту кнопку.

**Если написано «Мод установлен», всё готово. Устанавливать мод перед каждой игрой не нужно.** Действие обновления появится, если установленная версия отличается от пакета или не хватает файлов.

Для обновления старой версии используйте **«Установить / обновить»** при закрытой игре. Программа сохраняет резервные копии заменяемых файлов и не устанавливает обновление поверх неизвестных изменений.

## Шаг 3. Хост открывает игру для друга

1. Проверьте, что Radmin VPN работает и друг находится в вашей сети.
2. В BL4 LAN выберите **«Создать игру»**.
3. В поле **«Мой адрес»** выберите строку с **Radmin VPN**. Для домашней LAN выберите домашний адаптер.
4. Нажмите **«Скопировать адрес»** и отправьте его другу.
5. Нажмите **«Запустить игру»**.
6. Загрузите персонажа и дождитесь появления в игровом мире.
7. Дождитесь автосохранения, переключитесь в BL4 LAN и нажмите **«Создать хост»**.
8. Дождитесь перезагрузки локации и сообщения **«Хост готов»**. Теперь друг может входить.

Создание хоста перезагружает локацию. Не нажимайте эту кнопку в главном меню.

Оставьте BL4 LAN и Radmin VPN открытыми во время игры.

## Шаг 4. Друг подключается к хосту

1. В BL4 LAN выберите **«Подключиться»**.
2. Вставьте адрес, который хост скопировал для вас.
3. Нажмите **«Запустить игру»** и дождитесь главного меню.
4. Переключитесь в BL4 LAN и нажмите **«Подключиться»**.
5. Следите за сообщением в нижней части программы: там появится состояние соединения или причина ошибки.

**Пример адреса:** `26.1.2.3:7777`. Это пример — используйте адрес своего хоста.

Друг вводит адрес **хоста**, а не свой собственный. Хосту вводить адрес друга не требуется.

Штатная кнопка **«Подключиться» внутри Borderlands 4** обращается к SHiFT. Для этого LAN-мода нажимайте кнопку в **программе BL4 LAN**.

## Если не подключается

Проверьте по порядку:

1. На обоих ПК одинаковые сборки игры и пакет мода.
2. Оба видят друг друга в одной сети Radmin VPN.
3. У хоста уже написано **«Хост готов»**.
4. Друг использует адрес адаптера Radmin VPN именно хоста. Порт — **7777**.
5. Если Windows запрашивает доступ к сети для игры, разрешите его для вашей LAN/VPN. При блокировке соединения проверьте разрешение Borderlands 4 в брандмауэре; игровой порт — **7777/UDP**.
6. Прочитайте сообщение программы. Если хост не ответил, примерно через 45 секунд появится сообщение о тайм-ауте.

**«Открыть журнал»** показывает подробности. **«Скопировать сведения»** копирует диагностику, которую можно отправить вместе с описанием проблемы. Автоматической отправки нет.

Если пользуетесь клавишами: **F6** создаёт хост из игрового мира, **F7** подключает по адресу, сохранённому в лаунчере, **F8** проверяет состояние. Для первого запуска удобнее кнопки программы.

## Как поменять ник

1. Закройте игру.
2. Откройте **«Настройки»** в BL4 LAN.
3. Введите имя в поле **«Ник игрока»** и нажмите **«Сохранить ник»**.
4. Запустите игру снова.

Смена ника доступна для установок с поддерживаемым файлом настроек имени. Предыдущее значение сохраняется в резервной копии. Идентификатор аккаунта и файлы персонажей при смене ника не изменяются.

## Персонажи и обновление

Новая установка использует обычных персонажей игры. Если в старой версии уже был выбран отдельный профиль с персонажами, обновление сохраняет прежний выбор. Перенос и объединение сохранений автоматически не выполняются.

## Что проверено

Проверены подключение двух клиентов на одном ПК и синхронизация движения. Также есть пользовательское сообщение об успешном подключении через Radmin VPN.

Полная кампания, бой, добыча, переходы между картами и восстановление после разрыва связи не прошли полную проверку. Сообщение о соединении подтверждает вход игроков, но не исправность всех игровых сценариев.

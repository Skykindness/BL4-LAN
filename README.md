# BL4 LAN · by skykindness

**0.2.13** · [English](README-EN.md) · [简体中文](README-ZH-CN.md)

Кооператив Borderlands 4 по LAN или VPN. Лаунчер позволяет создать хост, подключиться по IP и поменять ник. В 0.2.13 мод восстанавливает задания и планшеты при первом обнаружении убежищ после создания хоста. [Скачать в Releases](https://github.com/Skykindness/BL4-LAN/releases) · [Как нашли и исправили баг](docs/SAFEHOUSE-FIX-RU.md)

## Как играть

1. На обоих ПК закройте игру и распакуйте **весь** `BL4-LAN-v0.2.13.zip`. Откройте `BL4-LAN.exe`, выберите папку игры с `OakGame` и нажмите **«Установить / обновить»**. Устанавливать нужно один раз и при обновлении.
2. Используйте одинаковые сборки игры и мода. Подключитесь к одной локальной сети или одной сети Radmin VPN. Для VPN берите адрес хоста из этой сети.
3. Оба нажмите **«Продолжить»** и загрузите своих персонажей в мир. Хост нажимает **«Создать хост»** и ждёт перезагрузки области. Гость нажимает **«Подключиться»** и вводит адрес хоста, например `26.1.2.3:7777`. Оставьте лаунчер открытым.

Язык лаунчера выбирается через **RU / EN / 简体中文**. Ник можно изменить в настройках лаунчера. Он применяется после перезапуска игры.

## Клавиши и команды

**F6** — создать хост, **F7** — войти по сохранённому адресу, **F8** — посмотреть статус. Если в консоли открыто текстовое меню `mods`, выйдите из него через **Q → Enter**.

| Команда | Действие |
| --- | --- |
| `bl4lan host` | Создать хост после загрузки персонажа |
| `bl4lan join IP:7777` | Подключиться по адресу хоста |
| `bl4lan status` | Проверить состояние сессии |

## Совместимость и диагностика

- Исправление убежищ проверено на `Oak2-Win64-4906557` и включается только на этой сборке игры.
- Личную сложность можно выбрать в **Esc → Настройки сессии → Сложность → Применить**. Выбор гостя сохраняется при входе. Влияние на редкий лут и масштабирование сложности на 3–4 игроков пока не подтверждены.
- У верхних аватаров и счётчика группы, штатного «+», ников через стены и отдельных состояний HUD остаются ограничения. Полное прохождение и сессии на 3–4 игроков ещё требуют отдельной проверки.
- Если возникла проблема, возьмите ZIP-отчёты с обеих сторон из `BL4-LAN-Data/Reports` в папке игры. Отчёты не отправляются автоматически и не содержат сохранений.

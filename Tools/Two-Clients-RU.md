# Два клиента на одном ПК

Это только способ локальной проверки. Для игры с другом на другом компьютере скрипт не нужен.

Обновление 3 ноября: флаг `-NoMovies` удалён. В сравнительной проверке на одном сохранении с ним после «Продолжить» оставался режим CutsceneIntro, блокирующий движение и обзор; без него оба вида ввода были разблокированы. Не добавляйте этот флаг для ускорения запуска.

1. Установите одинаковую версию мода. Закройте игру.
2. Откройте PowerShell в этой папке и выполните:

```powershell
& .\Start-Two-Clients.ps1 -GameDirectory 'D:\Games\Borderlands 4'
```

Скрипт откроет два окна 960×540 и выведет их PID. Копируются только небольшие сохранения в TwoClientProfiles/Host и TwoClientProfiles/Guest; исходные сохранения не перезаписываются. При следующих запусках используются уже созданные тестовые профили. Не запускайте один и тот же тестовый профиль дважды одновременно.

3. В обоих окнах нажмите «Продолжить» и дождитесь собственного игрового мира.
4. В игровой консоли первого окна выполните:

```text
bl4lan host
```

Дождитесь перезагрузки мира. В консоли второго окна:

```text
bl4lan join 127.0.0.1:7787
```

Если открыто именно меню `mods`, сначала выйдите из него через Q и Enter. После этого вводите bl4lan-команды. Отдельного лаунчера для этих ручных команд не требуется.

Для запуска только одного окна используйте `-Client Host` или `-Client Guest`. Для другой папки игры добавьте `-GameDirectory 'D:\Games\Borderlands 4'`.

Для связи между двумя ПК вместо 127.0.0.1 нужен адрес хоста в общей LAN/VPN. Порт 7787 выбран только для этого локального скрипта; обычная установка использует 7777. Двум клиентам требуется больше оперативной и видеопамяти. Проверка синтаксиса скрипта выполнена; сама локальная пара проверялась отдельным внутренним помощником с тем же способом разделения профилей.

# 0.2.1 · by skykindness

- Встроена выбранная иконка SK с голубой звездой: окно, исполняемый файл, панель задач.
- Хосту виден собственный адрес, гостю — поле адреса друга.
- Проверка установленной версии: после установки её кнопка скрывается, остаются два игровых шага. Установка появляется только при необходимости.
- В разделе «Настройки» оставлены только папка игры и ник.
- Убраны диагностические параметры отдельного профиля и прогрева шейдеров. Прежний выбор персонажей при обновлении сохраняется.
- Подсказки меняются вместе с ролью, копирование адреса подтверждается сообщением.
- Штатная кнопка Connect требует SHiFT; интеграция со штатным меню в этот выпуск не входит.
- Сетевая часть мода 0.2.0, установщик и обработка состояний сохранены.

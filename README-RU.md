# BL4 LAN · by skykindness

**0.2.9** · [English](README-EN.md)

Кооператив по LAN / VPN. Добавлено автоматическое восстановление пустого ника напарника; в локальной паре у гостя появилось имя над персонажем хоста. Карта, телепорт и живые полосы HP/щита подтверждены пользователем на двух ПК в 0.2.7.

## Как играть

1. При закрытой игре распакуйте весь архив на обоих ПК. В BL4-LAN.exe выберите папку игры → «Установить / обновить». Устанавливать повторно перед каждой игрой не нужно: готовая установка определяется автоматически.
2. Используйте одну домашнюю LAN либо общую сеть Radmin VPN. На обоих ПК нужны одинаковые сборки игры и мода. Для VPN берите адрес хоста из этой VPN.
3. Оба нажмите «Продолжить» и загрузите своих персонажей в мир. Хост выбирает «Создать хост» и ждёт перезагрузки. Гость выбирает «Подключиться» и вводит адрес хоста. Лаунчер оставьте открытым.

## Личная сложность

В игре: **Esc → Настройки сессии → Уровень сложности → Применить**. Каждый выбирает свой режим. Выбор, сделанный до входа, передаётся серверу автоматически один раз. В локальной паре сервер сохранил хосту «Сложно», а гостю получил «Легко» без повторного изменения после входа. UVHM / True Mode — отдельные настройки. Размер бонусов к редкому луту и масштабирование группы на 3–4 игроков пока не подтверждены.

## Если нужны команды

Откройте игровую консоль. Если вы внутри `mods`, сначала **Q → Enter**. Затем:

- `bl4lan host` — создать хост после загрузки персонажа;
- `bl4lan join АДРЕС_ХОСТА:7777` — подключиться;
- `bl4lan status` — проверить состояние.

Для диагностики достаточно обычной попытки подключения. ZIP сохраняется автоматически в папке игры → **BL4-LAN-Data → Reports**. Передавайте последний отчёт с обоих ПК. Контрольные снимки появляются через 2, 10 и 30 секунд после готовой группы. Видео, сохранения, дампы и пакеты не собираются; автоматической отправки нет.

Возможные зависания входа, аватары и счётчик группы ещё исследуются. Ник через сплошную стену и новое восстановление на двух отдельных ПК требуют проверки. Штатный «+» пока не подключает к LAN-хосту. На клиенте смена разрешения/режима окна проверена без вылетов; на хосте ещё нет.

Для локальных тестов не добавляйте `-NoMovies`: в сравнительной проверке с ним после «Продолжить» оставалась блокировка управления CutsceneIntro. Обновлённый помощник запуска двух клиентов этот флаг не использует. Проверка 0.2.9 проведена на двух клиентах одного ПК; это не гарантия прохождения всей кампании без ошибок.

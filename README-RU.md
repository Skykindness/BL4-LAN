# BL4 LAN · by skykindness

**Русский** · [English](README-EN.md) · **[Скачать 0.2.5](https://github.com/Skykindness/BL4-LAN/releases/tag/v0.2.5)**

Кооператив Borderlands 4 на двух ПК через LAN/VPN. На обоих компьютерах нужны одинаковые сборки игры и версия мода. Язык лаунчера: **RU / EN** вверху окна.

## 1. Подготовьте сеть

- Через интернет: установите [Radmin VPN](https://www.radmin-vpn.com/ru/). Один создаёт сеть и передаёт другу название и пароль, второй присоединяется. Вы должны видеть друг друга в Radmin.
- В одной домашней сети VPN не нужен. Альтернативы: [ZeroTier](https://www.zerotier.com/download/), [Tailscale](https://tailscale.com/download), [Hamachi](https://vpn.net/); с модом отдельно не проверялись.

## 2. Установите мод — один раз на каждом ПК

1. Скачайте **BL4-LAN-v0.2.5.zip**, распакуйте целиком и откройте **BL4-LAN.exe**.
2. В **«Настройки»** выберите папку игры с **OakGame**, нажмите **«Назад»**.
3. При закрытой игре нажмите **«Установить / обновить»**, если кнопка появилась.

**«Мод установлен» — повторять установку перед каждой игрой не нужно.** Для обновления используйте новый полный пакет на обоих ПК. Сменить ник можно в настройках при закрытой игре.

## 3. Подключитесь

**Оба:** запустите игру, нажмите **«Продолжить»**, загрузите своего персонажа и дождитесь видимого мира и интерфейса. Из главного меню подключаться нельзя.

**Хост:** выберите **«Создать игру»**, скопируйте адрес адаптера Radmin VPN (или домашней LAN) и отправьте другу. После автосохранения нажмите **«Создать хост»**. Дождитесь перезагрузки локации и **«Хост готов»**.

**Друг:** выберите **«Подключиться»**, вставьте адрес **хоста** и нажмите **«Подключиться»** один раз. Пример формата: `26.1.2.3:7777`.

Оставьте лаунчер и Radmin открытыми; лаунчер можно свернуть в трей. Штатная кнопка SHiFT для этого мода не используется.

## Если не получилось

Проверьте адрес, одинаковые версии, загрузку персонажей и готовность хоста. Разрешите игре доступ к вашей LAN/VPN в брандмауэре Windows; порт **7777/UDP**.

При чёрном экране или обрыве оставьте лаунчер открытым до двух минут. Ссылка на отчёт появится внизу. Пришлите по ZIP с обоих ПК из **папка игры → BL4-LAN-Data → Reports**. Отправка только вручную; видео и сохранения не собираются.

В 0.2.5 получено сообщение об успешном подключении двух ПК с первой попытки. Длительная стабильность, полная кампания и подсветка напарника ещё не проверены полностью.

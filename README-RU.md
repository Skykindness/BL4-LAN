# BL4 LAN 0.2.12 · by skykindness

[English](README-EN.md) · [简体中文](README-ZH-CN.md)

Кооператив Borderlands 4 по LAN/VPN. В 0.2.12 исправлено проверенное зависание перехода между областями и добавлен китайский интерфейс запуска.

1. Закройте игру у обоих игроков. Распакуйте **весь архив**. В BL4-LAN.exe выберите корневую папку игры с OakGame → «Установить / обновить». Установка нужна один раз или после обновления.
2. Используйте одинаковые сборки игры и мода. Подключитесь к одной LAN или одной сети Radmin VPN; для VPN используйте адрес хоста из Radmin.
3. Оба игрока нажимают «Продолжить» и загружают своих персонажей в мир.
4. Хост нажимает «Создать хост» и ждёт перезагрузки области. Гость нажимает «Подключиться» и вводит IP хоста, например `26.1.2.3:7777`.
5. Оставьте лаунчер открытым. Язык переключается через RU / EN / 简体中文. Ник меняется в настройках и применяется после перезапуска игры.

Резервные команды игровой консоли: `bl4lan host`, `bl4lan join IP:7777`, `bl4lan status`. Клавиши: F6 — хост, F7 — вход по адресу лаунчера, F8 — статус. Если открыто текстовое меню mods, сначала Q → Enter.

Личная сложность: Esc → Настройки сессии → Сложность → Применить. Сохранён выбор гостя при входе; бонусы лута и масштабирование на 3–4 игроков не подтверждены.

**Известные ограничения:** в новых убежищах при первом обнаружении в коопе могут не появиться задание и планшет; это не исправлено. Есть ограничения верхних аватаров/счётчика группы, штатного «+», отображения ника через стены и некоторых состояний HUD. Полное прохождение и 3–4 игрока не проверены целиком. Экспериментальные команды safehouse/pyexec в релиз не включены.

При проблеме: папка игры → BL4-LAN-Data → Reports. Нужен ZIP от хоста и гостя; автоматической отправки нет. Сохранения не входят в отчёты.

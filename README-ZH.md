# BL4 LAN · by skykindness

[Русский](README-RU.md) · [English](README-EN.md) · **简体中文** · **[下载 0.2.7](https://github.com/Skykindness/BL4-LAN/releases/tag/v0.2.7)**

通过局域网/VPN 在两台 PC 上进行 Borderlands 4 合作联机。双方需要相同的游戏版本和模组版本。启动器顶部可切换 **RU / EN / ZH** 语言。

## 1. 准备网络

- 通过互联网联机：安装 [Radmin VPN](https://www.radmin-vpn.com/)。一人创建网络并把名称和密码发给好友，另一人加入。双方需能在 Radmin 中看到彼此。
- 在同一家庭局域网内则无需 VPN。替代方案：[ZeroTier](https://www.zerotier.com/download/)、[Tailscale](https://tailscale.com/download/)、[Hamachi](https://vpn.net/)；未针对本模组单独测试。

## 2. 每台 PC 安装一次

1. 下载 **BL4-LAN-v0.2.7.zip**，完整解压后打开 **BL4-LAN.exe**。
2. 打开 **设置**，选择包含 **OakGame** 的游戏文件夹，然后点击 **返回**。
3. 在游戏关闭的状态下，如果出现 **安装 / 更新** 按钮请点击它。

**显示「模组已安装」后，每次游玩前无需重复安装。** 更新时请在两台 PC 上都使用新的完整安装包。修改昵称请在游戏关闭时于设置中进行。

## 3. 连接

**双方：** 启动游戏，点击 **继续**，载入自己的角色，等待游戏世界和界面完全可见。不要直接从主菜单加入。

**主机：** 选择 **创建游戏**，复制你的 Radmin VPN（或家庭局域网）地址并发送给好友。等待自动保存完成后点击 **创建主机**。等待区域重新加载并显示 **主机就绪**。

**加入方：** 选择 **加入游戏**，粘贴**主机**的地址，点击一次 **连接**。格式示例：`26.1.2.3:7777`。

保持启动器和 Radmin 开启；启动器可以最小化到托盘。本模组不使用游戏自带的 SHiFT 联机按钮。

## 手动连接

双方需先通过 **继续** 载入角色。切换到英文输入法，按 **反引号 / 波浪号键（\` / ~）** 打开控制台，输入命令并按 **回车**。

| 命令 | 作用 |
|---|---|
| `bl4lan host` | 创建主机；当前区域会重新加载。 |
| `bl4lan join 26.1.2.3:7777` | 加入主机。把示例替换为**主机的地址**。省略端口则使用 7777。 |
| `bl4lan join` | 使用启动器保存的地址加入。 |
| `bl4lan status` | 在控制台/启动器中查看连接状态。 |

默认快捷键：**F6 — 创建主机**，**F7 — 按启动器地址加入**，**F8 — 查看状态**。F8 不会重新连接。

**命令无法识别？** 输入 `mods`，选择 **BL4 LAN** 对应的编号。如果显示 **Disabled**，输入 `E` 并回车。然后输入 **\`Q\` → 回车** 退出模组菜单，再重试连接命令。如果列表中没有该模组，请检查安装。

## 如果连接失败

检查地址、双方版本是否一致、角色是否已载入，以及主机是否就绪。在 Windows 防火墙中允许游戏访问你的局域网/VPN；游戏端口为 **7777/UDP**。

遇到黑屏或断线时，请保持启动器开启最多两分钟。底部会出现报告链接。请从每台 PC 各发送一个 ZIP：**游戏文件夹 → BL4-LAN-Data → Reports**。报告仅手动发送；不会收集视频或存档。

0.2.7 已验证：加入方显示的原生主机名、队友卡片、护盾变化，以及载入角色后的重新加入。打开地图会生成两个原生玩家对象；各缩放级别下的图标渲染仍需验证。以上验证基于同一台 PC 上的两个客户端；双机局域网/VPN 测试另行进行。

队伍名单和头像可能显示不完整。HP 扣血、复活、场景切换和完整战役流程尚未完全验证。原生界面恢复针对已验证的游戏版本 **Oak2-Win64-4906557 / UE 5.5.4**；其他版本未经确认。这是预发布版本。

退出会话后，再次点击「继续」并载入角色。如果立即加入被判定为活动会话而拒绝，请等待状态刷新（最长 45 秒）后重试一次。

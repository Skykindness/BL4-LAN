# BL4 LAN · by skykindness

**0.2.9** · [Русский](README-RU.md) · [English](README-EN.md)

通过局域网 / VPN 合作联机。新增队友空白昵称的自动恢复；本地双客户端测试中，加入方角色头顶显示了主机昵称。作者在 0.2.7 已确认地图标记、传送和实时 HP/护盾显示在两台 PC 上可用。

## 一起游玩

1. 关闭游戏，在两台 PC 上完整解压压缩包。在 BL4-LAN.exe 中选择游戏文件夹 →「安装 / 更新」。只需安装一次；启动器会自动识别已就绪的安装。
2. 使用同一家庭局域网，或加入同一个 Radmin VPN 网络。两台 PC 需要相同的游戏和模组版本。走 VPN 时请使用该 VPN 中主机的地址。
3. 双方点击「继续」，将各自角色载入游戏世界。主机选择「创建主机」并等待重载。加入方选择「连接」并输入主机地址。保持启动器开启。

## 个人难度

游戏内：**Esc → 会话设置 → 难度 → 应用**。每位玩家各自选择。入队前做出的选择会自动传给服务器一次。在本地双人测试中，服务器保留了主机的「困难」，并接收了加入方的「简单」，无需入队后再调整。UVHM / True Mode 是独立设置。稀有掉落加成的具体数值和 3–4 人队伍缩放尚未确认。

## 可选控制台命令

打开游戏控制台。如果 `mods` 菜单开着，先 **Q → Enter** 退出。然后：

- `bl4lan host` — 载入角色后创建主机；
- `bl4lan join 主机IP:7777` — 加入；
- `bl4lan status` — 查看连接状态。

普通连接尝试即可完成诊断。ZIP 报告自动保存在游戏文件夹 → **BL4-LAN-Data → Reports**。请分享两台 PC 的最新报告。队伍就绪后会在 2、10、30 秒进行定时快照。不收集视频、存档、内存转储、抓包，也没有自动上传。

加入卡住、队伍头像和人数统计仍在调查中。隔墙昵称可见性和新的恢复机制在两台独立 PC 上仍需验证。原生「+」按钮暂时无法加入局域网主机。客户端的分辨率/窗口模式切换已测试无崩溃；主机端尚未测试。

本地测试请勿添加 `-NoMovies`：在对比测试中该标志会导致「继续」之后 CutsceneIntro 输入锁残留。更新后的双客户端启动助手不含此标志。0.2.9 的验证基于同一台 PC 上的两个客户端；这不代表完整战役流程无故障。

在启动器中选择 **RU / EN / ZH**。[捐赠](https://www.donationalerts.com/r/skykindness)。
